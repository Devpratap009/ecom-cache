READING THE RESULTS

Hit or miss?

Cache hit means the catalog data came from L1 memory or L2 Redis. A cache miss means QuickMart fetched fresh data from MongoDB and then populated the cache layers.

Counters are process-wide and reset when the server restarts. Use “Probe catalog cache” more than once to see the cache warm up.
